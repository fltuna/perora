# Perora

日本語 | [English](README_EN.md)

Windows 用のスクリーンショットツールです。複数のモニターにまたがる画面から好きな部分を切り取って、矢印や文字を描き込み、そのままコピーしたりファイルに保存したりできます。

名前はラテン語の *per*（通って）と *ora*（縁）を合わせた造語で、画面と画面の境目を越えて撮る、という意味を込めています。

## できること

撮影すると、すべてのモニターの画面がその場で止まり、その上で残したい部分を選べます。選び方は 4 つです。

- ウィンドウ
- 矩形（モニターの境目をまたいでも引ける）
- モニター 1 枚
- 全モニターをまとめて 1 枚

ウィンドウを選んだときは、手前に重なっていた別のウィンドウは写らず、そのウィンドウだけが撮れます。

撮った画像には、そのまま描き込めます。

- ペン、マーカー
- 図形（四角形・楕円・線・矢印）
- テキスト、番号
- ぼかし、モザイク
- 切り抜き

描いたものはあとから選び直して、位置や大きさ、色を変えられます。

コピーと保存の形式は PNG・JPG・WebP から選び、元の大きさのまま出すか、指定した大きさに縮めるかも決められます。いつもの形式を設定で決めておき、その回だけ別の形式にすることもできます。保存なら複数の形式を一度に書き出せます。

撮影のあとは、画面の隅に小さなプレビューが出ます。今使っているアプリからキーボード入力を奪わないので、文章を打っている途中でも、手を止めずにそのまま撮って作業に戻れます。プレビューを出さずに編集画面を開く、またはクリップボードにコピーするだけ、という設定もあります。

ほかに、日本語と英語の切り替え、ライトとダークのテーマ、Windows と一緒に立ち上がる設定に対応しています。

## ダウンロード

[Releases](../../releases) にインストーラーがあります。今のところ Windows 専用です。

## 使い方

**Ctrl+Shift+H** で撮影を始めます。このキーは設定で変えられ、**Win+Shift+S** で Perora を呼ぶこともできます。撮影中は次のキーで選び方を切り替えます。

| キー | モード | 選び方 |
|---|---|---|
| `1` | スマート | クリックでウィンドウ、ドラッグで矩形 |
| `2` | ウィンドウ | 一覧から選ぶ |
| `3` | 矩形 | ドラッグで範囲を選ぶ |
| `4` | モニター | モニターをクリック |
| `5` | 全モニター | すべてを 1 枚に |

`Esc` でやめます。選んだ画像はクリップボードに入り、同時にプレビューにも表示されます。プレビューの画像をクリックすると編集画面が開きます。

それぞれの画面は、初めて開いたときに操作を順に案内します（ツアー）。画面の **i** ボタンを押せば、いつでも見直せます。

Perora は通知領域に常駐していて、そのアイコンをクリックすると設定のウィンドウが開きます。

### アップロード（任意）

撮った画像を [i.f2a.dev](https://i.f2a.dev) にアップロードし、そのリンクをクリップボードに入れる機能もあります。初期状態ではオフです。ログインしてアップロードをオンにしない間は、撮った画像がパソコンの外に送られることは一切ありません。

## ビルド

Rust（stable）と Node.js が必要です。

```bash
npm install
npm run tauri build      # インストーラーを作る（target/release/bundle に出力）
npm run tauri dev        # 開発中に動かす
cargo test --workspace
```

画面の文言は [`lang/`](lang) にあり、`en.json` が基準です。`%APPDATA%\dev.f2a.perora\lang` に `<言語コード>.json` を置くと、ビルドし直さずに言語を追加したり、文言を変えたりできます。
